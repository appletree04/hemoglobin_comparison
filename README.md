# Hemoglobin Comparison
--

This is a small project I am taking on to better understand the role of programming in biology.
Programming is a skill I learned for myself and it is something I have actually enjoyed. Although
I am currently enrolled on a biomedical science degree, I wish to better understand the use of
programming in biological fields.

The aim of this project is to take real world genomic data from the [NCBI database](https://www.ncbi.nlm.nih.gov/datasets/gene/) and manipulate
it to produce interesting results that explains something.

For this project, I am taking orthologous and paralogous alpha hemoglobin genes across four species
(*Homo sapiens*, *Pan troglodytes*, *Mus musculus* and *Danio rerio*).
